# Closbot (Kotlin)

Native Android (Kotlin) re-platform of [closbot](https://github.com/ryan-chambers/closbot), an
AI sommelier app originally built with Ionic/Angular.

This is a from-scratch rewrite, not a port: the original repo is treated as read-only reference
material, not code to be migrated line-by-line. See [docs/app-inventory.md](docs/app-inventory.md)
for the feature/architecture inventory of the original app that this rewrite is based on.

## Project rules

- The original `closbot` repo is never modified.
- No commits land directly on `main` — all work happens on branches.

## Status

Early setup — see `docs/` for planning documents.
